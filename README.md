One emoji, chosen to make a stranger smile: 🫶 (heart hands) — a warm, open gesture of kindness and gratitude. Friendly at first glance, universal to any stranger, and deliberately picked instead of the default smiley.

## Why this emoji

- **Warm at first glance:** two hands forming a heart reads instantly as kindness — no context, no caption needed.
- **Universal:** a gesture, not a face, so a stranger of any age or background reads it the same way, with no irony or in-joke that could land wrong.
- **Chosen, not default:** it is a deliberate pick for the moment, not the first smiley that comes to mind.
- **Right for a stranger:** it carries no intimacy, sarcasm or flirtation — just an open-handed offer of warmth.

The program writes exactly that one emoji to `/output/entry.txt` — 4 bytes of UTF-8, no trailing newline, nothing else.

## Run it

```sh
node main.ts
```

This writes exactly one emoji to `/output/entry.txt`.
